### PayNote - カードの使用記録

- カード名は、所有カードを事前に登録して、そこから選択。
- 場所は、コンビニ、ユニクロ、無印、等を登録して、選択するかテキスト入力。
- 日付は、入力日をデフォルト表示。変更可能。[now]ボタンで現在時刻。
- 金額は、整数で単位は円。設定で変更可能。
