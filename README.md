### PayNote - カードの使用記録

カード等の支払いをその場で記録する、スマホ向けの PWA。
データはブラウザの localStorage に保存するため、サーバーもアカウント登録も不要。

### 画面構成

ヘッダー右のアイコンで 3 つの画面を切り替える。

- **入力** … 支払いを記録する
- **履歴** … 記録の一覧・削除・CSV 出力
- **設定** … 通貨・支払方法・場所の管理

設定の左の **QR** ボタンで、このサイトの URL を QR コードで表示する（他の端末から開く用）。
QR 生成ライブラリ（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)）だけは、
このボタンを押した時にのみ CDN から読み込む。

### 入力

日付・金額・場所・支払方法を上から順に並べ、各行はラベルと入力欄を横に並べている。
入力欄の幅は全角 8 文字程度。

- **日付** … 当日をデフォルト表示。変更可能（時刻は扱わない）。
- **金額** … 設定した小数点以下の桁数に従う（既定は整数）。
- **場所** … 欄に直接入力できる。右端の ▼ で登録済みの候補一覧を開き、選択も可能。
- **支払方法** … 場所と同じく、直接入力と候補からの選択に対応。

記録時、候補にない場所・支払方法は自動的に候補へ登録される（設定画面での事前登録も可能）。

### 履歴

- 月ごとにグループ表示し、月合計を表示。
- 各記録の **編集** … 記録画面と同じレイアウトのフォームが開き、日付・金額・場所・支払方法を修正できる。
  フォームの下の「削除」でその記録だけを消せる。
- **全履歴削除** … 確認のうえ、記録をすべて削除する。場所・支払方法の候補は残る。
- **CSV 出力** … `日付,場所,金額,支払方法` の UTF-8（BOM 付き）で、Excel でそのまま開ける。
  ファイル名は `paynote_YYYY-MM-DD.csv`。

### 設定

- **通貨単位** … 表示に使う単位（既定は「円」）。`$`、`€` 等も指定可能。
- **小数点以下の桁数** … 0〜3 桁。金額の入力・表示・CSV 出力に反映される。
- **支払方法管理 / 場所管理** … 候補の追加・削除。

### データの保存

localStorage に保存する（キー: `paynote_records` / `paynote_cards` / `paynote_places` / `paynote_settings`）。
使用したブラウザ内にのみ残るため、機種変更やブラウザのデータ削除で消える。
残しておきたい記録は CSV 出力しておく。

### 動作環境・技術構成

- フレームワークを使わない素の JavaScript（ES モジュール）と CSS のみ。ビルド不要。
  外部ライブラリの読み込みはない（QR コード表示時を除く）。
- PWA 対応（`manifest.json` + `service-worker.js`）。ホーム画面に追加して単独アプリとして起動でき、
  2 回目以降はオフラインでも動作する。
- ヘッダーの **PayNote** をタップすると更新チェックを行う（画面上の表示はなし）。
  キャッシュ済みのアプリ資材（HTML/CSS/JS/JSON）を配信中のものと比較し、
  異なっていればキャッシュを破棄して最新版を読み込み直す。

### ファイル構成

```
index.html               画面の骨組みだけ
style.css                スタイル
js/app.js                起点：ヘッダー・画面の切り替え・起動
js/store.js              保存データ(localStorage)と画面状態
js/ui.js                 DOM組み立て(h)・アイコン・候補付き入力欄
js/screen-record.js      記録の入力フォーム（新規・編集の兼用）
js/screen-history.js     履歴一覧・CSV出力・全履歴削除
js/screen-settings.js    通貨設定・候補（支払方法/場所）の管理
js/site.js               QRコード・更新チェック・Service Worker 登録
service-worker.js        キャッシュ制御
```

state を書き換える処理は `js/store.js` の更新関数（`setRecords` / `setCandidates` /
`addCandidate` / `updateSettings`）に集約してあり、保存漏れが起きないようにしている。

### ローカルでの動かし方

ES モジュールを使っているため、`index.html` を直接開くのではなくローカルサーバー経由で開く。

```bash
python -m http.server 8000   # または npx serve .
# ブラウザで http://localhost:8000 を開く
```
